# SEAM Share

**Tagline:** Move freely. Stay connected.

SEAM Share is a fast, elegant device-to-device sharing experience for Windows and Android.

## Identity
- Visual language: dark glass, soft depth, luminous violet-to-cyan gradient.
- Motion: fluid transitions, subtle spring physics, responsive feedback.
- Core idea: devices should feel like one connected space.

## Shared UI direction
Windows and Android use the same design language, spacing principles, iconography, gradients, surfaces, motion curves, and interaction patterns while respecting each platform's native conventions.
